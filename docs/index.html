Review when you choose

A familiar reveal-and-rate flow schedules each card with FSRS: Again, Hard, Good or Easy. The session uses a fixed pool, so new cards never jump in halfway through.

Good to know

Questions before downloading.

Is it an Anki replacement?

It can be, if you mainly study kanji and want less friction. It also works well beside Anki: import a text-only .apkg deck and let the widget keep a small pool visible.

Does it need the internet?

No. Normal study is completely local. Cards, settings, and review history stay in a SQLite database on your computer.

Why might SmartScreen warn me?

The current build is not code-signed yet. The source and SHA-256 checksums are public, and open-source code signing is being prepared.
