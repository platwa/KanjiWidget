## What's new / Что нового

### English

- Removed the nonfunctional update check and background requests. The installed version is still shown in **Settings → About**; check the website or GitHub Releases for newer versions.
- Removed the unused automatic updater from the application and release build. Studying continues to work offline with no account or telemetry.
- Fixed a timing issue that could hide a revealed answer while review intervals were being calculated.

### Русский

- Убраны неработавшая проверка обновлений и фоновые запросы. Установленная версия по-прежнему указана в разделе **Настройки → О программе**; новую версию можно посмотреть на сайте или в GitHub Releases.
- Удалён неиспользуемый механизм автообновления из приложения и сборки. Для обучения по-прежнему не нужны интернет и аккаунт; телеметрии нет.
- Исправлена ситуация, когда открытый ответ мог снова скрыться во время расчёта интервалов повторения.
