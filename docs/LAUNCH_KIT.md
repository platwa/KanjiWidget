## English community post

### Title

I made a free offline Windows widget for keeping kanji in sight — looking for early feedback

### Body

I wanted kanji to stay visible while I work instead of disappearing into another browser tab, so I made **KanjiWidget**.

It is a small Windows 10/11 desktop widget with:

- built-in JLPT N5 and N4 decks;
- furigana and example sentences;
- an active-recall widget mode that reveals readings and meanings on hover;
- Anki-style FSRS reviews;
- direct `.apkg` import without copying media;
- editable custom cards and decks;
- English and Russian UI;
- no account, ads, telemetry, or background network activity.

The project is completely free and open source under Apache-2.0. This is the first public release, so I am mainly looking for honest feedback: Is the widget useful during real study? Is anything confusing? Which missing feature matters most?

Screenshots, source, and downloads: https://github.com/platwa/KanjiWidget

Windows builds are currently unsigned, so SmartScreen may show an unfamiliar-publisher warning. SHA-256 checksums and the complete source are published with the release; free open-source code signing is being prepared.

## Product Hunt

**Name:** KanjiWidget

**Tagline:** A calm kanji widget for your Windows desktop

**Description:** Keep Japanese kanji quietly visible while you work, then review them with FSRS when you are ready. KanjiWidget is free, offline, open source, bilingual, and can import text cards directly from Anki `.apkg` decks.

**Maker comment:**

I built KanjiWidget because spaced-repetition tools are effective, but the material disappears as soon as the study session ends. The widget keeps a small rotating pool on the desktop without notifications or gamification. When it is time to review, the app switches to a familiar reveal-and-rate flow. Everything stays local and the source is public. I would especially value feedback from Windows users studying for JLPT N5–N4 or maintaining their own Anki decks.

- do not post the standalone application in `r/Anki` unless moderators explicitly approve it;

## First-cycle goals

- 30 installer or portable downloads;
- 5 GitHub stars;
- 3 actionable feedback reports;
- at least 1 user who imports a real `.apkg` deck successfully.

GitHub asset download counts are useful directional data but are not unique-user analytics. No application telemetry will be added for launch tracking.
